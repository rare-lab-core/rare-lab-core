### What I'm building

**Rare.lab** is a node-based visual editor + compiler that emits zero-dependency `.engine.ts` source. Designers create on canvas, the compiler emits production code, developers integrate. The moat is the compiler, the node graph, and 333+ product-situated primitives — every primitive describable in one sentence that lets a designer picture their product using it:

```
liquidParticles   →  fluid water for a landing-page hero
waterRipple       →  tap-to-disturb water surface on an interactive section
liquidTrail       →  metallic cursor ribbon trailing across hero copy
lightTrail        →  neon streak following a button hover
motionTracking    →  HUD overlay tracking for a video element
```
